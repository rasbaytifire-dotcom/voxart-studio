# 🎨 VoxArt Studio

**VoxArt Studio** est un éditeur interactif basé sur le web qui permet d'importer, de créer, de manipuler et d'exporter des modèles et illustrations 3D/Voxel directement depuis votre navigateur.

🔗 **Démo en ligne :** [VoxArt Studio Live](https://rasbaytifire-dotcom.github.io/voxart-studio/)

---

## ✨ Fonctionnalités principales

- 🧊 **Modélisation & Édition 3D/Voxel** : Créez et modifiez des formes volumétriques et des éléments 3D en toute simplicité.
- 🎨 **Palette de couleurs & Textures** : Personnalisez l'apparence de vos créations grâce à des outils de peinture et de sélection de couleurs.
- 🔄 **Manipulation interactive** : Rotation, zoom, translation et contrôle précis de la caméra dans un environnement WebGL.
- 📂 **Importation / Exportation** : Sauvegardez et partagez vos travaux sous différents formats 3D standards.
- 🌐 **100% Web & Sans Installation** : Accessible directement depuis n'importe quel navigateur moderne sans plugin externe.

## 🚀 Prise en main rapide

### 1. Accès direct via GitHub Pages
Rendez-vous simplement sur l'URL d'hébergement :
👉 **https://rasbaytifire-dotcom.github.io/voxart-studio/**

### 2. Lancement en local

Si vous souhaitez exécuter le projet localement sur votre machine :

```bash
# 1. Cloner le dépôt
git clone https://github.com/rasbaytifire-dotcom/voxart-studio.git

# 2. Accéder au dossier du projet
cd voxart-studio

# 3. Ouvrir l'application
# Vous pouvez simplement ouvrir index.html dans votre navigateur ou utiliser un serveur local
npx serve .
```

## 🛠️ Technologies utilisées

- **HTML5 / CSS3** : Structure et interface utilisateur (UI responsive).
- **JavaScript (ES6+)** : Logique applicative et gestion des états.
- **Three.js / WebGL** : Rendu graphique 3D haute performance dans le navigateur.

## 🎮 Commandes & Raccourcis (Guide utilisateur)

| Action | Commande / Souris |
| :--- | :--- |
| **Pivoter la vue** | Clic gauche + Glisser |
| **Déplacer la caméra (Pan)** | Clic droit + Glisser |
| **Zoomer / Dézoomer** | Molette de la souris |
| **Placer un voxel / outil** | Clic sur la grille 3D |
